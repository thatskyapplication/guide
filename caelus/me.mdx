## Setting up how Caelus looks

You can customise how Caelus looks in your server with an icon, banner, and bio! You can do this via `/configure me`.

## I got a rate limit error?

Did you receive this message when updating assets?

<Frame>
  <img

  <img

If so, you have encountered a rate limit. Discord doesn't allow users to update avatar icons or banners often in a short period of time. Simply wait a while, use the command, and try again later.
